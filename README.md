# 快递共配柜格管理系统 (Express Shared Locker Management)

工业物流风格的快递柜格管理前端系统，面向快递员与站点管理员，支持柜格占用可视化、入柜校验、取件追溯、超时件批量处理、异常标记与面单打印一体化能力。

## ✨ 核心特性

| 模块 | 功能 |
|------|------|
| **柜格总览** | 6×8=48 柜格网格，按尺寸（S/M/L）着色，按状态（空闲/占用/超时/异常）加角标 |
| **入柜模拟** | 包裹码输入、尺寸选择、快递员分配、尺寸匹配校验、重复入柜校验、自动推荐最优柜格 |
| **取件查询** | 按包裹码/快递员/柜格号多维度检索，已取件按钮禁用，防止重复操作 |
| **超时管理** | 超 24 小时自动进入超时列表，批量释放（必填备注），支持 CSV 导出 |
| **异常管理** | 异常原因+备注标记，异常柜格自动从入柜分配候选中排除 |
| **操作记录** | 批量释放记录、打印记录、导出记录，时间线展示 |
| **快捷键系统** | I/P/O/? 快捷操作，走与按钮同一套校验函数 |
| **面单打印** | 入柜后可打印 A6 标准面单，含模拟二维码和取件码 |
| **本地持久化** | Zustand + persist 中间件，柜格占用/超时/异常状态写入 localStorage，刷新不丢失 |

## 🔒 可验证的业务规则（Smoke 测试项）

1. **尺寸不匹配不可提交**
   - 入柜弹窗选中 L 码尺寸，若无对应大柜格，提交按钮自动 disabled
   - 错误信息：`包裹尺寸(L)与柜格尺寸(M/S)不匹配，无法入柜`

2. **重复包裹码入柜必拒绝**
   - 入柜弹窗填写已存在的包裹码（样例数据有 `SF20240610001` 等）
   - 校验失败：`该包裹码已存在，不能重复入柜`

3. **批量释放备注必填**
   - 超时列表勾选任意超时件 → 打开批量释放弹窗 → 不填备注直接点提交
   - 提交按钮 disabled + 错误提示：`批量释放必须填写备注`

4. **已取件柜格禁止二次取件**
   - 取件按钮显示「已取件」灰色 disabled 态

5. **异常柜格禁止自动分配**
   - 标记异常柜格 → 入柜时不会被推荐为目标柜格

## 🚀 快速开始

### 本地开发

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器 (http://localhost:5173)
npm run dev

# 3. 生产构建
npm run build

# 4. 本地预览生产构建
npm run preview   # http://localhost:4173
```

### Docker 部署

```bash
# 方式一：docker-compose
docker-compose up -d --build
# 访问 http://localhost:8080

# 方式二：纯 docker
docker build -t locker-management .
docker run -p 8080:80 --name locker-app locker-management
```

## 🛠 技术栈

- **框架**: React 18 + TypeScript 5 + Vite 5
- **状态管理**: Zustand 4 (with persist middleware → localStorage)
- **样式**: TailwindCSS 3 (工业物流深色主题)
- **图标**: Lucide React (线性图标)
- **字体**: JetBrains Mono (等宽柜格号) + Noto Sans SC
- **容器化**: nginx:alpine + Dockerfile + docker-compose
- **测试**: Node.js 原生 smoke 脚本 (HTTP + 静态断言)

## 🔄 正常 / 异常路径速览

### ✅ 正常路径（推荐体验顺序）

1. 打开入柜弹窗 (`I`) → 填 `TEST001` + M 尺寸 → 确认入柜 → 成功 Toast
2. 取件查询 (`P`) → 搜索 `SF20240610001` → 点「取件」→ 成功
3. 超时列表 (`O`) → 勾选 2 件 → 批量释放 → 备注 `联系用户未果` → 释放成功

### ❌ 异常路径（必验证）

1. **尺寸不匹配**：入柜 → 选 L 尺寸 → 在所有 L 柜被占满时，提交按钮应为 disabled
2. **重复包裹码**：入柜 → 填 `SF20240610001`（已有）→ 红色错误块：`该包裹码已存在`
3. **批量释放空备注**：超时页勾选 → 释放弹窗 → 不填备注 → 提交按钮 disabled + 红字提示
4. **已取件不可再取**：搜索 `SF20240610001` 取件后 → 再搜索 → 按钮显示「已取件」disabled
